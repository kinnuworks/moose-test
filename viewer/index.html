"Passed" means a real briefing whose sources the gateway saw the agent fetch. "Failed honestly" means the agent said it could not do the job and made nothing up: under a fault, that is the right answer. Controls: null writes nothing, so it must never pass; if it did, the grading would be wrong. single-search makes one search and one model call: the simplest agent that can pass, and the cost and failure baseline the real agents are measured against. "Contradicted by source" is an AI check, not part of the grade: for each citation the gateway saw fetched, a model compares the citing line with the page text the search returned. A claim the text does not cover counts as neither, since an agent may read more of a page than the gateway sees.

      Open-source research agents, run exactly as published, write the same pre-meeting briefings again and again while the gateway takes away their model or breaks their web search. Every number on this page comes from the gateway's own logs, not from the agents.

      514 runs of 2 research agents and 2 control agents, on 8 briefing tasks, under 6 conditions: Normal day, Model down, gateway fallback, Model down, no fallback, Search returns nothing, Search rate-limited (429), Planted false search result. The model is the same for every agent: anthropic/claude-haiku-5-5. Last run 2026-11-15 14:40 UTC.

      514 runs. Every number from the gateway, none from the agents.

      Named after the 1997 Swedish "moose test", a sudden swerve that tipped over a new car which had passed every normal drive.

      Gateway: Bifrost (model calls, routing-rule faults, Tavily relay). Search: Tavily. Source and method: see the repository README.
